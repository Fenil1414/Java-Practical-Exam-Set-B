# CEUE203 Practical Exam – Set B

**Course:** CEUE203 Object Oriented Programming  
**Institute:** CHARUSAT – Chandubhai S. Patel Institute of Technology

This repository contains Java solutions for both problems in **CEUE203 Practical Examination – Set B**.

## Contents

### Problem 1: Stationery Shop Receipts
Folder: `Problem1_StationeryShop/`

Concepts demonstrated:
- Classes and objects
- Constructors and `this`
- Private and final fields
- Static variables and methods
- Switch expressions
- Method overriding with `toString()`
- Input validation and totals

Run from the `Problem1_StationeryShop` folder:

```bash
javac Main.java
java Main
```

Sample input and expected output are in `sample-input.txt` and `sample-output.txt`.

### Problem 2: Notice Cleaner
Folder: `Problem2_NoticeCleaner/`

Concepts demonstrated:
- String methods and case conversion
- `StringBuilder`
- Splitting text into words
- Loops and conditional statements
- Word count, shortest word, keyword count, and vowel count

Run from the `Problem2_NoticeCleaner` folder:

```bash
javac Main.java
java Main
```

Sample input and expected output are in `sample-input.txt` and `sample-output.txt`.

## Requirements

- Java JDK 14 or later for switch expressions; JDK 17 is recommended.
- Run each problem separately because both solutions use the class name `Main`.
